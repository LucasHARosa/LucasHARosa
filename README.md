## Sobre

Sou **Software Engineer / Desenvolvedor Full-Stack** e Engenheiro Mecatrônico formado pela **Universidade de Brasília (UnB)**.

Atuo no desenvolvimento de produtos de ponta a ponta, com experiência profissional em **back-end, aplicações web e mobile**, trabalhando desde arquitetura, APIs e regras de negócio até interfaces, integrações e publicação de aplicativos.

Minha experiência inclui diferentes contextos, como **fintech, plataformas web, logística, sistemas corporativos, IoT e aplicações mobile em produção**.

* **Back-end:** Java / Spring Boot · Node.js / NestJS · Python / FastAPI / Django · Go
* **Front-end:** React · Next.js · TypeScript
* **Mobile:** React Native · Expo
* **Dados:** PostgreSQL · DB2 · MongoDB · Redis
* **Infra & Integrações:** Docker · Kubernetes · RabbitMQ · CI/CD · WebSockets · SSE
* **Engenharia:** APIs REST · Microsserviços · SOLID · testes automatizados · Git
